Getting started

Make your first video

Someone technical (usually Dan) sets this tool up on your computer once. After that, everything below is copy, paste, and wait.

1
Open the tool's folder in a command window

In File Explorer, open the Reel Studio folder Dan gave you. Click once in the address bar at the top, type powershell, and press Enter. A dark window will open — that's your command window, already pointed at the right folder.

2
Generate one test video

Paste this into the command window and press Enter. It makes exactly one video, so you can check things look right before generating a whole batch.

powershell 
npm run render:batch -- --chapters=0-0 --limit=1

The first thing it prints is a numbered list of chapters — see the tip below for what those numbers mean.

3
Watch the finished video

Open the output folder inside the tool's folder. Your video will be there as an .mp4 file — double-click to play it like any other video.

4
Happy with it? Generate the whole chapter

Same command, just drop --limit so it doesn't stop early. This produces one video per group of 3 phrases in that chapter.

powershell 
npm run render:batch -- --chapters=0-0
About chapter numbers. The tool counts chapters starting at 0, not 1 — so "Chapter 1" in the book is usually 0, "Chapter 2" is 1, and so on. Don't guess: run any command once and the very first lines printed are a list like 0: Posh විදිහට English කතා කරමු — that number is what goes in --chapters=. If you started the wrong thing, press Ctrl + C to stop it immediately.
It's safe to re-run. The tool remembers what it already made and skips those videos automatically — so if you run the same command again later (say, after more phrases are added to a chapter), it only generates what's new. To force it to redo everything anyway, add --force.
Look & feel

Choose a template

There are three different visual styles to choose from. Add --template= to any generate command — it defaults to Template 1 if you leave it out.

Phrase → Countdown → Meaning
--template=1

Template 1 — Classic

Light background. Each part of the reel is its own screen: the phrase, then the countdown, then the reveal.

Phrase stays on screen
--template=2

Template 2 — Side-by-side

Light background. The phrase shrinks and stays visible while the countdown runs, then the meaning appears underneath it — good for memorizing, since both are on screen together at the end.

Sinhala first, English revealed
--template=3

Template 3 — Reversed, dark

Dark background. Flips the game: shows the Sinhala meaning first and asks viewers to guess the English phrase.

powershell — example 
npm run render:batch -- --chapters=0-0 --template=2
Templates are independent — generating the same chapter in Template 2 and Template 3 won't overwrite or skip anything, so it's safe to try a chapter in all three and compare.
Sound

Turn narration on or off

By default, reels are silent except for background music and sound effects. Add --tts=true to have a voice read the English phrase and the Sinhala meaning aloud.

--tts=false (default)

Text on screen only, plus music and the countdown tick. Faster to generate.

--tts=true

Adds a spoken voice reading each phrase and its meaning — alternates between a male and female voice from one video to the next.

powershell — example 
npm run render:batch -- --chapters=0-0 --tts=true
Sound

Add more background music

The tool rotates through whatever tracks it finds in one folder — adding more is as simple as copying files in. No command needed, and nothing to tell the tool about it.

1
Find the music folder

Inside the tool's folder, open assets, then music.

2
Drop your track in

Copy any .mp3, .wav, .m4a, or .ogg file into that folder. That's it — nothing to rename or register.

3
It's in the rotation from your next generation onward

Every video you generate after this automatically has a chance of using the new track. Videos already made won't change.

Check the license before posting. Only add tracks you have the rights to use commercially. Music pulled from a platform's own free audio library (like Instagram's or Facebook's) usually only covers posting on that platform, not everywhere — check with Dan if you're unsure.
Sound

Make the voice-over easier to hear

If narration or sound effects sometimes get buried under the music, add --sidechain=true. The music automatically dips whenever someone's talking or a sound effect plays, then comes back up the moment it's quiet again — the same trick music producers use to keep a voice-over clear over a song.

powershell — example 
npm run render:batch -- --chapters=0-0 --tts=true --sidechain=true
Takes a bit longer. Each video needs an extra processing pass, so generating a whole chapter with this on takes somewhat more time than without it. This needs a separate tool called ffmpeg already installed on this computer (Dan sets this up) — if it isn't, the tool prints a warning and makes the video normally instead of stopping.
Results

Where your videos (and captions) end up

Every finished video is saved in the output folder, named after the chapter and phrases it covers — for example ch000-000-002.mp4 is chapter 0, phrases 0 through 2. A Template 2 or 3 version of the same phrases gets -t2 or -t3 added to the name, so nothing overwrites anything else.

A ready-made caption suggestion (with hashtags) is generated for every video too, saved alongside them in a file called manifest.json. It's a technical-looking file — ask Dan to pull the captions out for you if you don't want to open it yourself.

If something looks off

Troubleshooting

?
Nothing happens after I press Enter

It's probably working — the first video can take under a minute, but a full chapter can take a while since each video renders one at a time. Leave the window open and check the output folder for new files.

?
Red text appears and it stops

That's an error. Take a screenshot of the whole window and send it to Dan — don't try to fix it yourself.

?
A video looks or sounds wrong

Note which file it is (the exact name in the output folder) and what's wrong, and send both to Dan — pacing, colors, and audio balance are all things that can be adjusted.

Reference

Command cheat sheet

Every command starts the same way — mix and match the pieces on the right.

PieceWhat it does
npm run render:batch --

Always comes first. Starts the generator.

--chapters=0-0

Which chapter(s) to generate, by number (see the tip above about counting from 0). Use a range like 0-2 for chapters 1 through 3.

--limit=1

Stop after this many new videos. Leave it out to generate everything in scope.

--template=2

1, 2, or 3. Defaults to 1 if left out.

--tts=true

Turns on spoken narration. Defaults to off.

--sidechain=true

Ducks the music under narration/sound effects so they're easier to hear. Takes a bit longer. Defaults to off.

--force

Redo videos that already exist instead of skipping them.

powershell — everything at once 
npm run render:batch -- --chapters=1-3 --template=2 --tts=true
